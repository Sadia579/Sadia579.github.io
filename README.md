# Sadia Sultana — Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The Certifications section includes an interactive add/remove form. Certificates added in the browser are temporary and are not saved after a page refresh. Update the internship wording if you want to specify the exact YSSE role/title.
