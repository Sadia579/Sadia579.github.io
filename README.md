# Sadia Sultana — Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The Certifications section has an interactive add/remove form. Entries are only held in the current browser session and are not saved after a refresh.

Project descriptions are written as project concepts/planned features, rather than claiming that every feature is already implemented.
